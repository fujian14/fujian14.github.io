## Project Description
This Project focused on preparing a raw freelancer dataset for reliable analysis by identifying and resolving common data quality issues.

## Tools Used
SQL (MySQL)

## My Approach
Used SQL to inspect the dataset, identify duplicate records, handle NULL and blank values, standardize inconsistent data, and organize the cleaned data into a structured format ready for analysis.

## Goals
Successfully transformed a raw and inconsistent freelancer dataset into a cleaner, analysis-ready dataset that could be used confidently for further exploratory analysis and reporting.
