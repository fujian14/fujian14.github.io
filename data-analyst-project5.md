## Project Description
An interactive Tableau dashboard designed to visualize coffee shop sales performance and make important business metrics easier to explore.

## Tools Used
Tableau, Excel, data visualization

## My Approach
Prepared the dataset in Excel, connected the cleaned data to Tableau, created KPI cards and interactive charts, and added filters to allow users to explore sales by store, product, transaction activity, and price range.

## Goals
Created an interactive Tableau dashboard that turned coffee shop sales data into accessible visual insights, making revenue, transactions, top-performing stores, and product trends easier to analyze.
