## Project Description
An exploratory data analysis (EDA) project designed to investigate freelancer characteristics, earnings, job activity, and other patterns within the dataset.

## Tools Used
SQL (MySQL)

## My Approach
Applied SQL queries using filtering, grouping, aggregation, sorting, conditional logic, and other analytical techniques to investigate patterns and relationships across the freelancer data.

## Goals
Extracted meaningful patterns and trends from the freelancer dataset and converted raw records into structured insights that could support further analysis and business understanding.
