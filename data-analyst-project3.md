## Project Description
A dashboard project that transforms freelancer data into visual insights about earnings, job performance, experience levels, and freelancer trends.

## Tools Used
Power BI, Power Query, DAX

## My Approach
Imported and prepared the dataset, created calculated measures, built interactive visualizations, and organized key metrics into a dashboard that allows users to explore freelancer performance and trends.

## Goals
Built an interactive Power BI dashboard that transformed freelancer data into clear visual insights on earnings, job performance, experience levels, and freelancer trends to support data-driven decision-making.
